# 公开范围与验证

发布目标：kmjinyan-hash/xiangjiang-water-quality-demo。

本公开副本根据维护者授权整理，包含前后端应用、模型定义、推理权重、缩放参数、现有数据快照、地图资源、使用文档和第三方许可。原创部分仅供个人非商业参考，具体以根目录 LICENSE 为准。

排除训练程序及其存档写入流程、密钥与私人配置、账号数据库、运行日志、备份、缓存和原内部仓库历史。旧技术文档中的闭源要求、登录界面、旧启动器及训练命令仅为历史记录，不能作为当前公开版的运行说明；以根目录 README 为准。

验证包括：本机密钥值及常见凭据格式扫描、训练实现扫描、权重 weights_only 安全加载、14 个断面接口、5 个目标断面的实际推理、无需登录及共享 API 密钥的默认行为、前后端用户自带 API 模拟测试、独立前端构建、Compose 与 Caddy 配置检查。未调用真实收费大模型 API。

运行检查使用已有本地 Python/PyTorch 容器环境和容器临时数据目录。完整镜像从依赖源重新下载构建的流程仍依赖使用者网络及依赖源可用性。

GitHub Pages 展示 docs/demo 中的合成数据网页；完整后端与模型推理需在本机 Docker 中启动。
