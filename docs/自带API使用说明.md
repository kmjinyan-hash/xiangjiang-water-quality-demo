# 自带大模型 API

平台现在打开即用，无需登录、注册或管理账号。地图、历史数据、总氮预测和规则分析不需要大模型密钥。

## 配置自己的服务

1. 打开 `https://localhost:8443/`，或双击项目根目录 `启动.bat`。
2. 点击顶部“大模型 API”。
3. 使用方式选择“接入自己的 API（OpenAI 兼容）”。
4. 填写服务商提供的 Base URL、Model ID 和 API Key。
5. 可先点“测试连接”，收到成功提示后点“保存设置”。保存不强制测试。

服务地址通常以 `/v1` 结尾；也支持直接填写完整的 `/chat/completions` 地址。请以服务商实际提供的地址与模型名称为准。接口采用 OpenAI 兼容的 `POST /chat/completions` 协议，包含 `model`、`messages`、`stream` 等字段，以 `Authorization: Bearer` 传递密钥；原生格式不同的服务需通过兼容网关接入。

连接测试会发送一次简短请求，可能产生少量服务商费用。配置生效后，断面 AI 解读和报告生成均使用当前页面提供的配置。普通请求和 SSE 流式请求使用同一套设置。

## 密钥与停用

- API Key 只留在当前页面内存，刷新或关闭页面后需重新填写。
- 浏览器仅保存服务地址与模型名称，不保存 Key，也不会自动恢复启用状态。
- Key 经本机后端转发至填写的服务，不写入服务器配置、数据库或报告。
- 每个页面独立提供自己的配置，不修改共享环境变量。默认不使用原 `.env` 中的服务端大模型密钥。
- “停用并清除密钥”会清空当前页面的 Key，并恢复规则分析；取消弹窗不会改变已生效的配置。

## 本机使用边界

当前无账号版本的 Docker 端口仅绑定 `127.0.0.1`，不向局域网或公网开放。旧账号数据库保留，旧账号管理接口在无账号模式下返回 404；旧管理台页面已移入项目外归档。

首次访问可能出现本机自签证书提示，需要使用者手动确认。部署到其他机器或对外开放前，另行确定 HTTPS 和访问控制配置。

## 验证记录

本次已在隔离测试容器中使用本地模拟接口验证普通调用、流式报告、不同请求的模型与密钥隔离、无共享密钥回退、地址校验和跨源预检，没有消耗真实 API 额度。实际服务检查通过：免登录读取 14 个站点、5 站数据状态与预测、主页面及全部脚本加载。

`node tests/test_frontend_byok.cjs` 另行验证了前端默认停用、普通与流式请求的配置传递、浏览器存储不包含密钥、非法地址校验及停用清除密钥。这些逻辑测试不替代证书确认后的浏览器视觉验收。
