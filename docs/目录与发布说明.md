## 两份前端产物

两份产物的接口地址用途不同，不能直接互相覆盖。修改前端时编辑 `frontend/`，再从项目根目录执行对应构建命令。

本地 `启动.bat` 打开 `dist/index.html`，配合现有 `https://localhost:8443` 接口：

```powershell
python scripts/build_frontend.py --api-base https://localhost:8443
```

nginx 前端镜像与 `deploy/docker-compose.hot.yml` 使用同源版本：

```powershell
python scripts/build_frontend.py --out build/dist-docker
```

以上本地地址只适用于现有本机环境。面向其他机器交付时，按实际部署地址设置接口地址；同源部署使用空 `apiBase`。完整部署流程见 `部署与访问.md`、`容器化说明.md` 和 `容器与热更新.md`。
