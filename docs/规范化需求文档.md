## 一、 项目愿景与目标
构建一个集成“全量数据采集、自动化特征工程、深度学习推理、可视化结果展示”于一体的极简 Web 平台。通过自研的 `HiFuse-DCS` 改进模型（依托于 `train_code.py` 训练所得的 `sequential_river_tn_model.pth`），实现河流关键下游断面（ST10-ST14）总氮（TN）指标的精准与多任务实时预测。

## 二、 系统架构与数据链路 (遵循第一性原理与KISS原则)

系统按功能职责切分为四大解耦模块：**采集池（后台静默运行） $\rightarrow$ 映射清洗层（Data Pipeline） $\rightarrow$ 推理引擎（Inference层） $\rightarrow$ 数据看板（Web UI层，受权限保护）**。

### （一）核心链路拆解
1. **第一池 - 原生态全量囤水（自动后台任务 Crawler_v2.py $\to$ Database）**：
   **【非用户触达端】** `crawler_v2.py` 作为稳固底座，每天由后台定时任务（Cronjob/Scheduler）静默独立执行 1 次。它严格根据网页展示规范抓取十余项原始水质指标，全量存入 Database。此行为以“广度备份”作为导向，对终端用户绝对透明，保障系统高速运转且互不干扰。
   
2. **第二池 - 适配拔模提纯（Database $\to$ CSV）**：
   在后台爬虫结束全量拉取后，系统脚本顺带从数据库词条池抽取最新数据。实施**定向抽样与映射清洗**（执行如“电导率” $\to$ `TDS` 等硬性转换，且忽略“氨氮”），将符合推理规范的数据持久化追写到 `data/*_processed.csv` 供模型备用。
   
3. **第三层 - 极速权限推理（Web 交互 $\to$ CSV $\to$ Model Inference）**：
   用户通过 Web 界面认证登录后，只需点击预测按钮，系统瞬间读取 `data/*.csv` 最新的连续 7 天数据序列（由后台爬虫早已制备完毕），交由预加载的 PyTorch 进行毫秒级的前向推理输出。

## 三、 具体交互功能详情

### 1 前端：强权限验证体系与可视化面板 (Web UI) 【权限部分已否决，见顶部变更记录】
**设计定位：** 现代化、沉浸式的 Dynamic Design，秉持极简的 Vanilla JS/CSS 构建暗黑风格/玻璃拟物界面。

- **入站关卡（Login/Registration Portal）**：
  - 强制认证防护。未注册或未登录游客无法窥视/调取推理程序或数据界面，建立独立的安全账号体系屏障。
- **主力工作台视窗（Dashboard Phase）**：
  - **动态双曲折线看板 (ECharts 驱动)**：支持所选站点（ST10-ST14）实时预测 TN 和历史真实 TN 值的平滑对比绘图。
- **数据推断操控舱**：
  - **预测引擎主按钮 (Trigger Prediction)**：拉动后端 API 发起快速推理，瞬间获得未来结果。该行为仅调取 CSV 不触碰后台爬虫。
- **本地历史资料库表**：
  - 展示被允许查阅的 STX 站点最近历史水质清单。
  - **专属数据导出通道**：提供明亮的“下载 CSV (Download CSV) ”按钮以便用户落库带走清洗好的数据，杜绝直接的 Crawler 执行触发。

### 2 后端：认证服务器与预载推理引擎 (Flask / FastAPI) 【认证部分已否决，见顶部变更记录】
1. **统一后端调度器 (Scheduler)**：专门挂载类似于 `APScheduler` 的后台心跳，负责每日深夜自启去抓取全量网面并洗入 CSV。
2. **模型生命周期对齐策略**：
   - Flask 启服即同时预载 `train_code.py` 的模型，并在内存运行 `prepare_data()` 反压生成完全一致的 `input_scalers` 与 `target_scalers` （保持特征工程 0 损失适配，这正是能预测准的核心）。
3. **隔离权限 API Endpoint**：包含 JWT 或 Session Token 放行的 `/api/predict` 与 `/api/data_export` 等访问口，确保平台私密性。
