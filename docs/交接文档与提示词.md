## 一、当前运行状态（可直接用）

```powershell
# 启动
docker start wq wq_web          # 或双击项目根目录的 启动.bat
```

| 东西 | 地址 | 说明 |
|---|---|---|
| 主应用（前端） | 双击 `dist/index.html`（`file://`） | 纯静态 HTML，不需要任何服务器 |
| 管理台 | `https://localhost:8443/admin/` | 用户、角色、按站点授权 |
| API | `https://localhost:8443/api/*` | 容器内 Flask，不对外发布端口 |

- 容器 `wq`：Flask，**不发布任何端口**，只在 Docker 内网 `wq_net`
- 容器 `wq_web`：Caddy，绑 `127.0.0.1:8443`，只发 `/admin/` 与 `/api/*`
- 局域网访问不到（8443/8080/5000 均不可达）

### 修改前端后的构建

```powershell
python scripts/build_frontend.py --api-base https://localhost:8443
docker restart wq_web          # 只影响 /admin/；主应用是 file:// 直接刷新即可
```

`build_frontend.py` 会把 `frontend/` 复制到 `dist/`、替换所有 `%V%` 指纹（现在 16 处）、
把 `apiBase` 注入 `dist/app.config.js`。

### 改动前后的守门检查

```powershell
python scripts/check_decoupling.py
```
三层：静态隔离（后端无 `dist/`、前端无 `flask`）、接口契约（前端调的 `/api` 都存在）、
互不影响实验（重启后端前端哈希不变 / 改前端后端响应不变）。**必须全绿**。

## 四、必须知道的技术事实（这些是踩出来的）

### 接口真实形状（**别信直觉**）

```
GET  /api/stations        -> [{id:'st10', code:'ST10', name:'涟水', role:'target', river, city, lon, lat, builtin}]
GET  /api/predict         -> {ST10:{actual_TN:2.99, predicted_TN:2.4268, last_recorded_date:'2026-04-01'}, ...}
                             ⚠ 只有 5 个预测断面，且**只有总氮**，没有 TP/CODmn
GET  /api/data_status     -> {}   ⚠ 实测是空对象，不要依赖它
GET  /api/ai_warning_rules-> {TN:{label,unit,warn:1.0,alarm:2.0},
                              DO:{... ,lowerIsWorse:true},
                              PH:{... ,isRange:true,lowAlarm,lowWarn,highWarn,highAlarm}, ...}
GET  /api/model_eval      -> {metrics:{ST10_TN:{MAE,RMSE,R2,MAPE,Pearson_r}},
                              sample:{ST10_TN:{true:[],pred:[]}}, caveat:'...'}
POST /api/ai_report/generate -> SSE，**event: 与 data: 分两行**
GET  /api/basin_boundary  -> {available, data:{type:'FeatureCollection',
                              features:[{geometry:{type:'Polygon', coordinates:[[[lon,lat],...]]}}]}}
                              ⚠ 5000+ 顶点；导出地图 PNG 时用它画边界
```

### 2026-10-21 续作时新查到的事实

- `GET /api/history/<sid>?limit=` **上限 200**（`min(max(limit,1),200)`）。
  每个断面的 CSV 有 1142 行，但接口只返回末尾 200 条，所以日历/时间轴
  覆盖的是"最近 200 条记录的日期跨度"，不是完整三年。
- 这 200 条在时间上**不连续**：2023-07 ~ 2024-01 逐日（194 条），
  然后 **778 天空档**，再到 2026-03/04（12 条）。日历热力图中间那段空白
  是数据本身没有，不是渲染漏了。
- `prediction_history` 目前每个断面只有 **1 条**（predict_date 2026-04-02），
  所以 ⑪ 时间轴做了"预测日期 ≥2 才用预测帧，否则回退实测回放"的分支。
- 高德底图瓦片（`webrd0*.is.autonavi.com` / `webst0*.is.autonavi.com`）
  实测返回 `Access-Control-Allow-Origin: *`。**但图片必须带 `crossOrigin`
  加载**，否则即使服务端允许，画布仍会被标记为污染，`toBlob` 抛 SecurityError。
  这就是 `views.js` 里 tileLayer 加 `crossOrigin: 'anonymous'` 的原因 ——
  删掉它，地图 PNG 导出就废了。
- `WQ.grade.ratioOf` 对 DO 原来用 `warn/实测`，与其它指标的 `实测/alarm`
  不是同一把尺子。已统一为 `alarm/实测`，等级判定 `levelOf` 未动。
- `views.js` 里原先自己抄了一份阈值比较（`levelOfValue`），已改为调用
  `WQ.grade.levelOf` 只做键名翻译（warn → warning）。**不要再抄第二份。**

### 前端调用纪律

1. **必须用 `WQ.data.*` / `WQ.api()`**，不要自己 `fetch` —— token 在闭包里，
   裸 fetch 拿不到会全部 401。
2. `WQ.data.predict()` 曾经写成 `post('/api/predict')`，后端只允许 GET，
   一直 405 被 catch 吞掉，表现为"数据一直空"。**接口方法要对齐**。
3. 依赖登录数据的模块，`mount` 在登录前会跑一次（那时 401），
   **必须在 `boot` 事件里再 load 一次**，否则停在空值。
4. `var TOKEN` 必须声明在**模块级**；放进 `api()` 里会导致 `login()` 取不到。
5. **流式（SSE）请求用 `WQ.stream(path, payload)`**，别自己 `fetch`。
   曾经在这里踩过两次：`fetch('/api/ai_report/generate')` 在 `file://` 下会被
   解析成 `file:///G:/...`，请求根本发不出去（表现为"AI 长报告一直生成失败"）；
   即便地址对了，裸 fetch 也不带 `Authorization`，token 模式下 401。
   `WQ.stream` 复用 `api()` 的 base/token 规则，只把响应体交给调用方读流。

### 图标与报告渲染（2026-10-21 修复，别改回去）

- **图标精灵必须内联在 `index.html` 里**（`.wq-sprite` 那块），
  `<use href="#i-map">` 用**同文档**引用；`WQ.icon()` 也只产出 `#id`。
  原因：主应用是双击 `dist/index.html`（`file://`），Chrome 把每个本地文件
  当作独立来源，跨文档 `<use href="assets/icons/icons.svg#id">` 会被拦掉，
  表现就是"所有按钮图标都没了"。原来的 `assets/icons/icons.svg` 已删除，
  改图标只改 `index.html` 里那一块。
- **报告正文要走 `WQ.md()`**。在线模型生成的报告把整篇文章放在 `summary`
  字段（1800+ 字、带 `##`/`**`），`content` 只是 151 字的数据摘录。
  之前用 `esc(summary)` 输出，页面上就是一大段带井号的文字（看着像"报告没了"）。
  现在：`summary` 长（≥400 字）就按正文排版；`content` 短则标成「数据摘录」。
  列表里的一行摘要用 `abstract()` 去掉标记后截断。
- **AI 报告只有 `report` 一种风格**。`llm.py` 里的 `style='brief'`（2-4 句短评）
  目前**没有被 `/api/ai_report/generate` 暴露**，前端也没有短评入口。
  要做"一句话解读"，需要后端接口接受一个 style 参数（一行改动），前端再在
  断面详情卡下方加一块 —— 属跨端改动，先问负责人。

### 环境坑

- PowerShell 里 `$hostname:8443` 会被解析成"驱动器限定变量"变空串，
  写变量要用 `${name}`，或改用单引号 here-string + 占位符替换。
  **同一个坑的第二种形态**：`"$base/api/history/$sid?limit=200"` 里的
  `$sid?limit` 会被当成一个变量名吃掉，请求变成 `/api/history/=200` → 403。
  拼 URL 一律写 `${sid}?limit=200`。
- PowerShell 默认禁止运行 `.ps1`（ExecutionPolicy）。临时脚本用
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -File xxx.ps1` 跑。
- 用 `Get-Content -Raw` + `WriteAllText` 处理中文文件会毁编码；
  一律用 `[System.IO.File]::ReadAllText/WriteAllText` 配 UTF8 实例。
  控制台里看到的中文乱码不代表文件坏了，判断文件内容要用 `read` 工具。
- `edit` 工具要求先 `read` 且文件未在外部被改；若被脚本改过会报
  "file changed since it was read"，此时改用 Python 补丁脚本插入。
- HTTPS 不能用 IP 访问（SNI 禁 IP 字面量），必须用主机名。
- 跨源 cookie 会被第三方 cookie 策略拦；本项目改用 **token**，所以前端
  可以 `file://` 打开。`WQ_COOKIE_SAMESITE` 目前对主应用无用。
- Caddy 站点块**必须写主机名**；只写端口时签不出证书，且日志不打错。
- **浏览器实测不必装 chromedriver**：本机 Selenium Manager 无法访问
  `googlechromelabs.github.io`（下载 driver 失败）。改用 Chrome 的
  `--remote-debugging-port` + `websocket-client` 走 CDP，可以完成
  登录、点按钮、读 `Runtime.exceptionThrown`/`Log.entryAdded`（即控制台
  SEVERE）与 `Page.captureScreenshot`。启动参数需要
  `--remote-allow-origins=*`、`--ignore-certificate-errors`、
  `--allow-file-access-from-files`。
- **构建产物用 `--keep`**：`build_frontend.py` 默认先 `rmtree(dist)`，
  而 `dist/admin` 正被 `wq_web` 容器 bind mount 着；删了再建可能让容器
  看到已删除的旧目录。加 `--keep` 就只覆盖文件、不动目录身份。
